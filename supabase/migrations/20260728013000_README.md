# Frontend Migration Set

These migration SQLs add missing columns and SQL RPC functions needed by the frontend. They are designed to be run sequentially, one file at a time, after the existing `20260728000003_active_sessions_and_concurrent_login.sql` migration.

## Execution Order

Run these files in the following order:

| # | File | Description |
|---|------|-------------|
| 1 | `20260728013000_add_missing_user_profile_columns.sql` | Adds missing columns to `user_profiles` (pronouns, city, country, website, join_date, banner_notifications_enabled, payout_paypal_email, owned_vehicle_ids, entrance audio settings, voice announcement, crown badge counts, gift totals) |
| 2 | `20260728013001_add_missing_stream_columns.sql` | Adds missing columns to `streams` (likes_count, gifts_value, is_featured, featured_until, boosted_until, featured_at, featured_by, cloudflare_recording_id, cloudflare_playback_url, agora_channel, total_gifts_coins, total_unique_gifters) |
| 3 | `20260728013002_add_missing_marketplace_columns.sql` | Adds missing columns to `marketplace_purchases` (fulfillment_status, payout_status, tracking fields, shipping fields, buyer/seller/item IDs, price/cost fields) |
| 4 | `20260728013003_add_missing_badge_and_entrance_columns.sql` | Adds missing columns to `badge_catalog` and `entrance_effects` |
| 5 | `20260728013004_add_missing_other_columns.sql` | Adds missing columns to `homeowners_insurances`, `court_sessions`, `stream_seat_sessions` |
| 6 | `20260728013005_add_key_rpc_functions.sql` | Creates key SQL RPC functions: `get_user_monthly_coins_earned`, `get_stream_seats`, `get_profile_statistics`, `get_weekly_family_task_counts`, `get_trollmers_week_start`, `get_trollmin_stats` |
| 7 | `20260728013006_add_remaining_rpc_functions.sql` | Creates additional SQL RPC functions: `get_active_streams_paged`, `get_active_event`, `get_active_giveaways`, `get_user_storage_breakdown`, `get_user_storage_replay_status` |

## Notes

- All `ALTER TABLE` statements use `ADD COLUMN IF NOT EXISTS` and `DEFAULT` values for safety
- All SQL functions use `SECURITY DEFINER` with `search_path` set to `public`, `extensions`
- Functions are granted to `authenticated` and `service_role` roles
- Functions are owned by `postgres`

## Verification

After running all migrations, verify with:

```sql
-- Check user_profiles columns
SELECT column_name FROM information_schema.columns WHERE table_name = 'user_profiles' AND table_schema = 'public' ORDER BY column_name;

-- Check streams columns
SELECT column_name FROM information_schema.columns WHERE table_name = 'streams' AND table_schema = 'public' ORDER BY column_name;

-- Check marketplace_purchases columns
SELECT column_name FROM information_schema.columns WHERE table_name = 'marketplace_purchases' AND table_schema = 'public' ORDER BY column_name;

-- Verify SQL functions exist
SELECT routine_name FROM information_schema.routines WHERE routine_schema = 'public' ORDER BY routine_name;
```
